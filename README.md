# Prueba Técnica: Científico de Datos en NEQUI

Este repositorio contiene el desarrollo de la prueba técnica para la posición de Científico de Datos en NEQUI. El objetivo principal es detectar **fraccionamiento transaccional**, una mala práctica que implica dividir transacciones en múltiples partes menores realizadas dentro de un período de 24 horas.

---
